# ตัวอย่าง / วันเวลา สีที่ตรวจได้ ค่า RGB ระดับผลตามเกณฑ์ จัดการ

ยังไม่มีประวัติการวิเคราะห์ฟิล์ม

สแกนและบันทึกผลตัวอย่างแรกได้ที่แท็บ "สแกนฟิล์ม"

หลักการและที่มาของโครงงานฟิล์มกะหล่ำปลีม่วง

กะหล่ำปลีม่วง (Red Cabbage: Brassica oleracea var. capitata f. rubra) มีสารพฤกษเคมีกลุ่มรงควัตถุสำคัญคือ แอนโทไซยานิน (Anthocyanin) ชนิดไซยานิดิน-กลูโคไซด์ (Cyanidin glucosides) ซึ่งมีคุณสมบัติโดดเด่นในการเปลี่ยนโครงสร้างโมเลกุลตามความเป็นกรด-ด่าง (pH indicator) และภาวะออกซิเดชัน-รีดักชันในสิ่งแวดล้อม

เมื่อนำสารสกัดแอนโทไซยานินมาขึ้นรูปเป็น แผ่นฟิล์มชีวภาพอัจฉริยะ (Smart Colorimetric Film) ด้วยเมทริกซ์พอลิเมอร์ธรรมชาติ เช่น แป้ง หรือเซลลูโลส ฟิล์มจะทำหน้าที่เป็นเซนเซอร์ตรวจจับสารเคมี ละออง หรือไอระเหยกรดในบรรยากาศ (เช่น ซัลเฟอร์ไดออกไซด์ ไนโตรเจนไดออกไซด์ หรืออนุภาคที่เกาะตัวกับสารประกอบกรด)

กลไกการเปลี่ยนแปลงสีของสารแอนโทไซยานิน

  • สภาวะเริ่มต้น (สภาวะปกติ): ฟิล์มมีสีม่วง/ม่วงน้ำเงิน ซึ่งเป็นโครงสร้างสมดุลของ Quinonoidal base ในสภาวะกึ่งเป็นกลาง
  • เมื่อสัมผัสสภาวะกรด/มลภาวะที่มีความเป็นกรด: สารแอนโทไซยานินจะเปลี่ยนรูปเป็นไอออนบวก Flavylium cation ทำให้เฉดสีเปลี่ยนเป็นสีชมพู หรือสีแดง
  • เมื่อเกิดการสะสมตัวของละอองอนุภาค: นอกจากการเปลี่ยนสีทางเคมีแล้ว การเกาะจับของฝุ่นละอองบนผิวฟิล์มจะลดค่าความสว่าง (Luminance) และเปลี่ยนอัตราส่วนการสะท้อนแสงของช่องสี RGB อย่างเป็นสัดส่วน
ข้อกำหนดและจริยธรรมทางวิชาการ (Academic Compliance)

ระบบวิเคราะห์นี้ประมวลผลจากการเปลี่ยนแปลงของรหัสสี RGB บนแผ่นฟิล์มเท่านั้น ไม่ได้เป็นการตรวจวัดค่าความเข้มข้น PM2.5 โดยตรง และไม่มีการรายงานผลเป็นหน่วยไมโครกรัมต่อลูกบาศก์เมตร (µg/m³) โดยระบบจะจำแนกระดับผลตามเกณฑ์การทดลองที่ได้ศึกษาและเทียบมาตรฐานไว้ในห้องแล็บ

นิยามระดับการเปลี่ยนแปลง 3 ระดับตามเกณฑ์การทดลอง

ระดับต่ำ (Low)

ค่าสีของฟิล์มใกล้เคียงกับสภาวะเริ่มต้น (Baseline Purple) ไม่พบการเบี่ยงเบนของสี หรือค่าความต่างสี $\Delta E$ อยู่ในเกณฑ์ต่ำมาก

ระดับปานกลาง (Medium)

ฟิล์มเริ่มมีการเปลี่ยนเฉดสีอย่างสังเกตได้ (เบี่ยงเบนไปทางโทนชมพู หรือสีคล้ำลง) บ่งชี้ว่าเกิดปฏิกิริยาเคมีและการสะสมตัวในระดับปานกลาง

ระดับสูง (High)

ฟิล์มมีการเปลี่ยนแปลงของสีอย่างมีนัยสำคัญ สีเบี่ยงเบนออกจากสภาวะเดิมอย่างชัดเจนตามเกณฑ์ที่กำหนดไว้ในการทดลอง

คำแนะนำสำหรับการถ่ายภาพและควบคุมคุณภาพ (Quality Control)

  • การควบคุมแสง: ควรถ่ายภาพในบริเวณที่มีแสงสว่างสม่ำเสมอ หลีกเลี่ยงแสงสะท้อนจ้า (Glare) หรือเงาตกกระทบลงบนแผ่นฟิล์ม
  • พื้นหลังมาตรฐาน: ควรวางแผ่นฟิล์มบนแผ่นกระดาษสีขาวมาตรฐาน (White Reference Background) เพื่อลดการรบกวนของสีพื้น
  • การวางตำแหน่ง: จัดให้แผ่นฟิล์มอยู่กึ่งกลางกรอบเล็งเป้า (Reticle Guide) เพื่อให้ระบบดึงค่าสีจากบริเวณเนื้อฟิล์มที่สม่ำเสมอที่สุด

ตั้งค่าเกณฑ์การทดลอง (Calibration Baseline & Thresholds)

สามารถปรับเปลี่ยนค่าสีฟิล์มตั้งต้นและเกณฑ์การตัดแบ่งระดับ เพื่อให้ตรงกับผลการทดลองในห้องปฏิบัติการของท่านได้อย่างแม่นยำ

ค่าสีฟิล์มตั้งต้น (Baseline Purple Film)

เกณฑ์การตัดแบ่งระดับการเปลี่ยนแปลง (Color Delta Thresholds)

ค่าความต่างสีน้อยกว่านี้ถือเป็น "ระดับต่ำ"
หากตั้งแต่ค่านี้ขึ้นไปจะจัดเป็น "ระดับสูง"
